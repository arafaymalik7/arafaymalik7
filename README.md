## 🚀 Featured Projects

### 🎙️ [Realtime Voice AI Agent](https://github.com/arafaymalik7/realtime-voice-agent)

> A browser-based real-time voice agent — you speak, it listens, thinks, and talks back, interruptible mid-sentence with sub-second turn detection.

- ⚡ **Barge-in stops the agent in 64 ms**; end-of-speech → first audio ~1.5 s
- 🧩 Streaming pipeline: **Deepgram** (STT) → **LLM** (streaming + tool calling) → **ElevenLabs** (TTS), orchestrated by an explicit turn state machine
- 🛠️ Books appointments by voice via function calling; fails safely with a spoken fallback
- ✅ **27 unit tests**, GitHub Actions CI, multi-stage Docker, security-hardened WebSockets
